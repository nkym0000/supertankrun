# Super Tank Run 🍎🚜

N64 风格低多边形动作游戏：在**天安门广场**上驾驶坦克碾压滚动的水果得分。Godot 4.5。
模型、贴图、音效、音乐全部由代码程序化生成（唯一的外部素材是 Luckiest Guy 字体，Apache 2.0，见 assets/fonts）。

### 场景：天安门广场
整张地图在 `scripts/arena.gd` 里用代码搭出来（+Z 为北）：

| 方位 | 内容 |
|---|---|
| 北 | 长安街、金水河与五座金水桥、华表与石狮、天安门城楼（红墙五券门 + 金色重檐庑殿顶 + 画像与标语牌） |
| 中 | 人民英雄纪念碑（z=+20）、国旗杆（z=+42，旗面会飘）、两列各 5 盏九球华灯、4 座花坛 |
| 东西 | 人民大会堂 / 国家博物馆：米黄石柱廊建筑，贴着广场边缘 |
| 南 | 毛主席纪念堂、正阳门城楼与箭楼 |
| 远处 | 雾霾中的灰色院落与城市天际线 |

广场地面是平的（`Arena.height_at()` 恒为 0），铺装为花岗岩方砖，圆外过渡成沥青灰。
**可驾驶范围仍是半径 56 的圆**（`GameData.ARENA_RADIUS` 未改动）；大型建筑全在圆外，
圆内只有纪念碑 / 旗杆 / 华灯 / 花坛这 16 个障碍物。原点留空，所以标题与车库界面的环绕镜头不会穿模。

### N64 质感是怎么做的
- 427×240 内部分辨率 + 双线性放大 + 后处理（有序抖动、5-bit 色深、轻微水平模糊）：`shaders/n64_post.gdshader`
- 顶点光照（Gouraud）+ 小尺寸贴图（三平面/球面映射）：`shaders/lowpoly.gdshader`，贴图在 `scripts/textures.gd`
- 浓重距离雾、渐变天空穹顶、公告牌云、花坛精灵、点状阴影
- 圆润粗描边字体 + 九宫格光泽按钮 + 分段仪表

## 模式
- **战场对战**（标题界面「战场对战 BATTLE」）：换一张更大的地图（半径 **88**，不是广场的 56），
  场上有 **56 处掩体**——碉堡、沙袋墙、隔离墩、反坦克拒马、油桶、坦克残骸，外加弹坑和土堤边界，
  远处是雾霾里的废墟与黑烟柱。
  6 辆坦克（你 + 5 台电脑）从外圈均分的出生点开打，**各自为战**：电脑互相之间也会打，不是围攻你。
  每辆车都有装甲（180），**挨炮弹或者被撞都会掉血**，撞击伤害按相对速度算（双方都掉，冲得快的少掉）。
  5 台电脑各用一种和你不同的涂装，方便分辨。打光所有人 +5000，每击毁一辆 +1500，另按生存时间计分。
- **经典**（标题界面「开始游戏」）：原来的玩法，场上会出地雷。
- **大蒜模式**（标题界面「大蒜模式 GARLIC」）：同一张地图，场上混入**紫皮大蒜**（和橙子/地雷差不多大，
  紫白条纹，在浅色花岗岩广场上很显眼）。**碰到或炸到大蒜都算失误**——所以这个模式里不能见人就轰，
  开炮前要看爆炸范围里有没有蒜。每次失误 **-5 秒**并清空连击，累计 3 次直接收场。
  全程零失误额外 +2000 分。该模式不出地雷，大蒜是唯一的威胁；场上大蒜上限 7 个。

## 玩法
- 压扁水果得分；连续压扁累积**连击倍率**（最高 ×10），每 10 连击 +2 秒。
- 樱桃 50 · 苹果 100 · 橙子 150 · 香蕉 250 · 西瓜 500（**速度太慢压不碎**，需加速）· 金苹果 2000（会逃跑，+3 秒）。
- 红色**地雷**：被炸眩晕、-3 秒、连击清零。
- **主炮**：炮塔独立瞄准，开炮打出会缓慢下坠的炮弹，落点范围内的水果按和碾压完全相同的规则计分、吃同一套连击。
  打中地雷只会把它安全引爆（不扣时间），所以清场很有用；西瓜不用加速也能一炮打碎。
  弹仓打空后会一发一发自动装填，HUD 右下角是弹药格，准星显示的是**炮口实际指向**（炮塔有转速限制，不会瞬间跟上鼠标）。
- 每局得分换算金币，回车库买**涂装**（6 种）和**改装**（发动机/履带/压路辊/涡轮/连击计时器/燃料箱/主炮/弹药架/炮塔马达，各 6 级）。
- 存档位置：`user://supertankrun_save.json`

## 代码结构（scripts/）
- `main.gd` 状态机、驾驶/碰撞/压扁/连击、摄像机、车库接线
- `gamedata.gd` **所有可调数据**：涂装、升级、水果参数、升级→数值公式
- `tank.gd` 坦克模型 + 驾驶物理 + 炮塔转向/后坐　`fruit.gd` 水果模型 + 滚动/逃跑/反弹　`shell.gd` 炮弹
- `arena.gd` 两套场景：天安门广场 + 战场（`kind` 决定建哪套）　`tank_ai.gd` 对战模式的电脑坦克大脑
- `fx.gd` 粒子/果汁污渍/履带印
- `sfx.gd` 程序化合成音效与音乐　`game_ui.gd` 全部界面　`mesh_builder.gd` 低多边形网格生成器　`textures.gd` 程序化贴图　`mats.gd` 材质工厂
- `save_game.gd` 存档

## 想改的地方
- 画面“糊”的程度：`main.gd` 里的 `PIXEL_SHRINK`（2=640×360，3=427×240，4=320×180）
- 雾的浓度/颜色：`arena.gd` 的 `_build_env`；光照颜色：`lowpoly.gdshader` 顶部常量；抖动/色深：`n64_post.gdshader`
- 建筑配色：`arena.gd` 顶部的 `C_WALL` / `C_ROOF` / `C_MARBLE` 等常量
- 城楼位置与体量：`GATE_Z` / `GATE_FRONT` / `WALL_H`；中式屋顶由 `_hip_roof()` 与 `_eave_skirt()` 生成
- 广场障碍物布局：`_build_plaza()`（华灯 / 花坛 / 纪念碑 / 旗杆）
- 加新涂装/升级/水果：改 `gamedata.gd`（水果模型在 `fruit.gd` 的 `_build_mesh`）
- 渲染器已设为 GL Compatibility（复古风足够，兼容性最好）
